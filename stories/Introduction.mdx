# Polarize UI

A React + shadcn/ui library for showing scientific data honestly, on one token file
(`tokens.json`). Charts are [visx](https://visx.airbnb.tech/).

## The rule

**A label may never be hidden. Its explanation must be.**

- `<Tier>` always shows colour, word and glyph. It has no compact form.
- `<Note>` shows only a marker; its explanation lives in the documentation drawer.
- `<Value kind="measured">` and `kind="predicted"` never share styling.

## Chart rules

1. A threshold is drawn on the same axes as the series it judges.
2. A log axis says so in its own label, and refuses a non-positive domain.
3. Decimation is printed on the panel, never silent.
4. Colour comes from the theme — `--chart-n` for series, `--tier-*` for evidence — never a literal.

## Two ways in

- **React / Vite:** `import { LineChart, Tier, Note } from "@polarizetech/polarize-ui/react"` and
  `src/index.css`. This is what this Storybook shows.
- **Zero-build pages:** `design.css` + `design.js` (custom elements), unchanged. See `INTEGRATION.md`.
  Do not load `design.css` and the React theme in the same document — both define `--accent`.

Every chart in this Storybook is drawn from **synthetic** data.
